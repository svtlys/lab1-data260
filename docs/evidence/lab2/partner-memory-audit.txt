compatibility conclusion:
- memory collections and database selection are compatible with the current Mongo foundation.
- memory topic, envelope, producer, and consumer behavior are compatible with the current Kafka foundation.
- the implementation is additive at the file level, but assistant route/loop/schema/config changes require manual integration and regression tests.
- do not integrate the partner branch wholesale and do not run scripts.seed_memory --kafka during integration.
- recommended order: integrate memory utility/tests, manually merge assistant context and route/schema changes, run focused tests, then add a separate worker Compose service.
