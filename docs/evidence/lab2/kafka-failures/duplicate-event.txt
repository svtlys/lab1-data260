Observed result
---------------
- Producer result: published_count=2.
- activity_logs count for the demo event: before 0, after 1.
- processed_events count for the demo event: before 0, after 1.
- The first delivery was processed; the second was skipped by event_id idempotency.
- Group offsets after processing: p16.job.created partition 0 current 2,
  log end 2, lag 0; partitions 1 and 2 were 0/0 with lag 0.
- The worker emitted no application-specific log lines in the temporary
  container; the database counts and committed offsets are the evidence.

The first helper attempt inherited MONGO_READS_ENABLED=false and exited before
processing. It produced zero writes. The isolated worker was rerun with
MONGO_READS_ENABLED=true and produced the result above.

Safety
------
No existing activity log, processed event, application record, memory record,
or evidence file was deleted or modified. The temporary worker was stopped
after verification. No source file was changed and no topic was created.
